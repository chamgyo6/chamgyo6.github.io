# 참교육 클라이밍

클라이밍장 매너 빌런을 응징하는 브라우저 액션 게임 프로토타입. 빌드 없이 파일을 브라우저로 열면 바로 할 수 있어요.

| 파일 | 버전 |
|---|---|
| `index.html` | **메인: 3D** — 3인칭(GTA식 등 뒤 카메라) ↔ 쿼터뷰(2.5D), 게임 중 `V`로 전환. Three.js r149 (CDN, 실패 시 `vendor/three.min.js`) |
| `2d.html` | 초기 2D 횡스크롤 버전 |
| `config.js` | 온라인 랭킹(Firebase) 설정. 비워두면 이 기기 기록만 남음 |
| `firestore.rules` | Firebase 랭킹 보안 규칙 (콘솔에 붙여넣기) |

## 사이트로 배포하기 (빌드 필요 없음, 정적 파일 그대로)
**방법 1. GitHub Pages** (저장소를 공개로 바꿔야 함. 무료 계정은 비공개 저장소에 Pages 불가)
1. Settings → General → 맨 아래 Danger Zone → Change visibility → Public
2. Settings → Pages → Source: *Deploy from a branch* → 브랜치 선택, 폴더 `/ (root)` → Save
3. 1~2분 뒤 `https://<계정>.github.io/seoakng/` 에서 열림

**방법 2. Netlify** (저장소 비공개 유지)
1. app.netlify.com → Add new site → Import an existing project → GitHub → `seoakng`
2. 브랜치 선택, Build command 비움, Publish directory 비움 → Deploy
3. `https://<이름>.netlify.app` 에서 열림 (Site settings에서 이름 변경 가능)

## 온라인 랭킹 켜기 (Firebase, 무료)
누구나 로그인 없이 기록을 올릴 수 있게 됩니다 (익명 로그인, 각자 자기 기록만 수정 가능).
1. console.firebase.google.com → 프로젝트 추가 (Google Analytics는 꺼도 됨)
2. 빌드 → Authentication → 시작하기 → 로그인 방법 → **익명** → 사용 설정
3. 빌드 → Firestore Database → 데이터베이스 만들기 → 위치 `asia-northeast3 (서울)` → 프로덕션 모드
4. Firestore → **규칙** 탭 → 이 저장소의 `firestore.rules` 내용을 그대로 붙여넣고 게시
5. ⚙ 프로젝트 설정 → 일반 → 내 앱 → 웹(`</>`) 앱 추가 → 보이는 `apiKey`, `projectId` 를 `config.js` 에 넣기
   (웹용 apiKey는 공개돼도 되는 값이고, 보안은 4번 규칙이 담당)

## 조작 (2D)
| 동작 | 키보드 | 터치 |
|---|---|---|
| 이동 | ← → / A D | 왼쪽 스틱 |
| 벽 잡기 · 오르기 / 내려가기 | ↑ ↓ / W S | 스틱 위/아래 |
| 점프 · 벽에서 뛰어내리기 | Space / K | 점프 |

| 동작 | 키보드·마우스 | 터치 |
|---|---|---|
| 이동 | W A S D / 방향키 | 왼쪽 스틱 |
| 달리기 | Shift | 스틱 끝까지 |
| 시점 회전 (3인칭) | 마우스 드래그 | 오른쪽 화면 드래그 |

## 규칙
- (3D) 📅 오늘의 챌린지: 날짜(한국 시간)로 정해진 같은 빌런 라인업·오늘의 규칙(빌런 체력 +1 / 투명 사회 / 직원 기분 최고 / 초크 폭풍 / 응원단 출동)으로 모두가 겨루고, 랭킹판의 "오늘" 탭에 따로 기록된다.
- (3D) 📸 하이라이트: 판 중 가장 멋진 순간(보스 KO > 바디슬램 > 던지기·퇴장·멘붕 > 일반 KO)이 자동 캡처돼 게임 오버 화면에 뜨고, 사진으로 저장할 수 있다.
- (3D) 게임 오버 화면의 "결과 공유"로 점수·칭호·게임 링크를 복사해 카톡 등에 붙여넣을 수 있다.
- (3D) 점수에 따라 칭호: 매너 인턴 → 매너 지킴이 → 매너 보안관 → 참교육 전문가 → 클라이밍장 수호신 → 전설의 참교육러.
- (3D) 빌런은 빌런짓을 하기 전까지 평범한 회원처럼 보인다. 빌런짓을 하는 순간 "빌런 발각!"과 함께 빨간 마커가 뜬다. 발각 전에 때리거나 돌아다니는 일반 회원을 때리면 경고.
- (3D) 🏆 명예의 전당(상위 10명): 내 사이트에서는 `config.js`에 Firebase를 넣으면 누구나 등록, 비워두면 이 기기 기록만. claude.ai 아티팩트에서는 아티팩트 공유 DB를 쓰며 참여자(Contributor) 이상만 등록 가능.
- (3D) 카운터 직원은 우리 편: 빌런을 치우면 박수치거나 감동해서 울고, 참교육이 쌓이거나 웨이브를 클리어하면 선물(프로틴 쉐이크·무료 이용권·신상 암벽화·초크볼)을 던져준다.
- (3D) 빌런을 처치하면 구경꾼 회원들이 환호하며 멘탈 +3, 큰 참교육이면 +8. 회원을 때리면 야유.
- 빌런이 살아 있으면 **멘탈**이 깎인다. 0이 되면 끝.
- 벽에서 등반 중인 **선량한 회원**을 (나도 벽에 붙어서) 때리면 경고. 3번이면 출입금지.
- 삼각대·열린 락커 앞에서 ↑ = **몰래 장난**. 빌런이 멘붕하면 보너스 +800.
- 벽 위에서 떨어져 빌런을 덮치면 **바디슬램** 한 방 KO.
- 날아간 빌런이 다른 빌런과 부딪히면 **도미노**, 출구 밖으로 날리면 **퇴장 보너스**.
- TOP 홀드를 잡으면 **완등**: 멘탈 회복 + 9초간 점수 2배.
