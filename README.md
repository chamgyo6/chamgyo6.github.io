# 참교육 클라이밍

클라이밍장 매너 빌런을 응징하는 브라우저 액션 게임 프로토타입. 빌드 없이 파일을 브라우저로 열면 바로 할 수 있어요.

| 파일 | 버전 |
|---|---|
| `index.html` | 2D 횡스크롤 |
| `3d.html` | 3D: **3인칭(GTA식 등 뒤 카메라)** ↔ **쿼터뷰(2.5D)**, 게임 중 `V`로 전환. Three.js r149 사용 (CDN, 실패 시 `vendor/three.min.js`) |

## 조작 (2D)
| 동작 | 키보드 | 터치 |
|---|---|---|
| 이동 | ← → / A D | 왼쪽 스틱 |
| 벽 잡기 · 오르기 / 내려가기 | ↑ ↓ / W S | 스틱 위/아래 |
| 점프 · 벽에서 뛰어내리기 | Space / K | 점프 |
| 공격 (3타째 발차기, 공중에선 드롭킥) | J / X | 공격 |

## 조작 (3D)
| 동작 | 키보드·마우스 | 터치 |
|---|---|---|
| 이동 | W A S D / 방향키 | 왼쪽 스틱 |
| 달리기 | Shift | 스틱 끝까지 |
| 시점 회전 (3인칭) | 마우스 드래그 | 오른쪽 화면 드래그 |
| 공격 | J / 클릭 | 공격 |
| 점프 · 벽에서 뛰어내리기 | Space | 점프 |
| 멱살 잡기 → 던지기 · 벽 잡기 · 녹화 정지 · 자물쇠 | E | 잡기 |
| 시점 전환 | V | 시점 버튼 |

## 규칙
- (3D) 빌런은 빌런짓을 하기 전까지 평범한 회원처럼 보인다. 빌런짓을 하는 순간 "빌런 발각!"과 함께 빨간 마커가 뜬다. 발각 전에 때리거나 돌아다니는 일반 회원을 때리면 경고.
- (3D) 🏆 명예의 전당: claude.ai 아티팩트로 열면 공유 DB에 각자 최고 기록이 올라가는 랭킹판(상위 10명). 등록은 참여자(Contributor) 이상 권한이 필요하고, 보기 전용은 랭킹만 볼 수 있다. 로컬 파일로 열면 랭킹판은 숨겨진다.
- (3D) 카운터 직원은 우리 편: 빌런을 치우면 박수치거나 감동해서 울고, 참교육이 쌓이거나 웨이브를 클리어하면 선물(프로틴 쉐이크·무료 이용권·신상 암벽화·초크볼)을 던져준다.
- (3D) 빌런을 처치하면 구경꾼 회원들이 환호하며 멘탈 +3, 큰 참교육이면 +8. 회원을 때리면 야유.
- 빌런이 살아 있으면 **멘탈**이 깎인다. 0이 되면 끝.
- 벽에서 등반 중인 **선량한 회원**을 (나도 벽에 붙어서) 때리면 경고. 3번이면 출입금지.
- 삼각대·열린 락커 앞에서 ↑ = **몰래 장난**. 빌런이 멘붕하면 보너스 +800.
- 벽 위에서 떨어져 빌런을 덮치면 **바디슬램** 한 방 KO.
- 날아간 빌런이 다른 빌런과 부딪히면 **도미노**, 출구 밖으로 날리면 **퇴장 보너스**.
- TOP 홀드를 잡으면 **완등**: 멘탈 회복 + 9초간 점수 2배.

## 빌런
| 빌런 | 민폐 | 참교육 |
|---|---|---|
| 매트 죽돌이 | 낙하 구역에 앉아 폰 보기 | 때리기 / 벽 위에서 바디슬램 |
| 짐 폭탄 | 매트에 가방·물병·신발 방치 | 물건을 출구로 차면 주인이 따라 나감 |
| 초크 폭격기 | 쉬는 사람들 옆에서 초크 털기 | 때리기 |
| 들이대기 | 루트 겹치게 붙고 "안 겹쳐요~" | 벽에서 걷어차기 |
| 촬영충 | 삼각대 앞 지나가면 "갈았다" | 몰래 녹화 정지(↑) → 멘붕 / 삼각대 툭 |
| 락커 방치범 | 락커 열어두고 등반 | 자물쇠 잠그기(↑) → "비번 뭐야?!" 멘붕 |
| 훈수충 | 요청 없는 베타 | 벽 끝으로 몰아서 때리기 |
| 센터 고인물 (보스) | 어깨빵·초크 폭탄·부하 소환 | 웨이브 5마다 등장 |
